Buffalo East Side Lead Exposure Risk

This revised version uses real ZIP-area geography on top of an OpenStreetMap basemap. The application was still assembled as an AI-built HTML project using prompt decisions, selected sources, and exploratory risk logic rather than a traditional GIS workflow.

How to read the map

Each outlined ZIP area is clickable while the ZIP code hovers above. The fill color represents a concern level based on the project’s selected indicator, especially visible lead-paint violation points from an Open Data Buffalo file. They were also classified based on supporting soil information and county public-health context provided by Open Buffalo.

Important: this represents potential risk and patterns of concern. It does not confirm exposure, poisoning, or contamination at every parcel inside a ZIP area.

Methods

The map uses this revised project ZIP set only: 14204, 14206, 14208, 14210, 14211, 14212, 14214, and 14215.

A demographics overlay can be toggled on to add average household income, percentages of age groups, and top-race context from Open Data Buffalo.

ZIP fill categories were assigned using simple, prompt-driven logic:

  • Higher concern for the strongest overlap of many violation points and context from supporting articles.
  • Moderate concern where several lead points and soil/public-health context overlap.
  • Lower concern where some visible lead evidence appears but the pattern is weaker.
  • No concern where the embedded excerpt did not show lead sample points, though county concern context may still exist.

Source references
